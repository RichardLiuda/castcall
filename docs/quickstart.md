# 从零到上线

## 1. 标准部署流程

不管是自己动手、用网页向导，还是交给 AI 助手，都是同一套五步。每一步做完都有能看见的结果。

### 第 0 步：装环境

- Python 3.9 以上（核心服务只用标准库）。
- **一图流依赖（建议装，建站时默认会生成一图流）**：

  ```bash
  python3 -m venv .venv-poster
  .venv-poster/bin/pip install -r requirements-poster.txt
  .venv-poster/bin/playwright install chromium
  # Linux 还要中文字体：sudo apt install fonts-noto-cjk
  ```

  仓库里有 `.venv-poster/` 就会自动用它，不用另外配置。没装也能建站，只是一图流那一步会跳过并提示怎么装，装好后在后台点「生成一图流」补上。

### 第 1 步：准备名单（三选一）

| 来源 | 怎么做 |
|---|---|
| 自己有名单 | 群公告、表格、截图整理成下面的文本格式，存成 `名单.txt` |
| 按作品先出一版 | `python3 server/artsearch.py roster CLANNAD Kanon -o 名单.txt`：从 Bangumi 拉作品的主角、配角（简体中文名），角色全部空缺，CN 再补 |
| 先空着 | 不导入，建站后在后台加团、加角色 |

名单格式（`server/importer.py`）：

```
## CLANNAD                    ← 一部作品一个团；只有一部也建议写上，团名就是作品名
> 光坂外景，妆造自理          ← 「>」开头写进团说明
古河渚 云果                   ← 角色 + CN，空格 / Tab / 冒号 / 竖线分隔都行
冈崎朋也                      ← 只有角色 = 空缺，可以报名
## 摄影 / 后勤                ← 团名有「摄影 / 后勤 / 妆娘 / staff」会设成工作组（不配图）
摄影 阿光
```

CSV / 从 Excel 复制的表格也行，表头写 `团,角色,CN`。

### 第 2 步：在网页向导里建站（自动配图 + 一图流）

带着名单启动服务器：

```bash
python3 server/server.py --prefill 名单.txt --title "活动名"
```

终端里会打印一个 `http://127.0.0.1:5510/setup?t=…` 链接（末尾的口令只出现在这里，防止别人抢先设置你的网站）。打开它，名单和活动名已经填好，团长在网页上：

1. **单团 / 多团**：按名单自动选好，核对一下
2. **活动信息**：日期、开场时间（填了就有倒计时）、地点、咨询联系方式、报名要留哪种联系方式
3. **角色名单**：核对预填的名单，直接在框里改；下面实时显示读到几个团、几个空缺
4. **报名要填什么**：勾选身高 / 年龄 / 性别 / 样片 / 所在城市…，或者自己出题，每项选「选填」或「必填」
5. **管理密码**

点「建好它」后，完成页上会依次亮起：

1. **建站**
2. **自动配图**：从 Bangumi / AniList 给每个团找封面、给每个角色找立绘，只配有把握的，其余跳过。工作组不配。
3. **生成一图流**：海报网页 + JPG，页面抬头出现「一图流」入口。

两步都不会让建站失败：断网、没配上、缺一图流依赖，完成页上会写原因和补救办法。这台设备会自动登录成管理员。

没有名单（第 1 步选了「先空着」）就不带 `--prefill`，向导里选「先空着」。

**没有浏览器的时候**（只能 ssh 的服务器、脚本批量建站），用命令行一次做完，效果相同：

```bash
python3 init.py --title "活动名" --import 名单.txt --fields "身高,样片*,性别" \
  --date 2026-12-12 --start 2026-12-12T11:00:00+08:00 --location "地点" --contact "微信 abc123" --yes
```

`--fields` 就是向导第 4 步：逗号分隔，`*` 结尾是必填，其余选填，认不出的字当成自定义题（详见 [config.md](config.md#报名额外要填的fields)）。
不给 `--password` 时会随机生成一个管理密码，**只打印这一次**。不想自动配图 / 生成一图流：`--no-art` / `--no-poster`。

### 第 3 步：启动、验收

```bash
python3 server/server.py        # http://127.0.0.1:5510/ ，右下角的锁是后台
```

打开页面确认四件事：

1. 团、角色、CN 和名单一致；一部作品 + 摄影后勤是**单团页**，不是两张卡。
2. 封面、立绘配上了；抬头有「一图流」入口（没装依赖的话没有，见第 0 步）。
3. 空缺角色点「报名 →」能打开报名表。
4. 右下角的锁 → 输密码 → 进得了后台。

### 第 4 步：补漏

- 没配上的立绘：后台编辑角色 → 「找立绘」点选，或者上传自己的图。批量重试：工具条「一键配图」。
- 名册、图片改过之后，工具条「生成一图流」重新生成（不会自动重建）。
- logo、标签页图标、一图流大图：工具条「站点素材」。

### 第 5 步：上线

见 [deploy.md](deploy.md)（systemd + 反向代理）。服务器上装不了 Chrome 的话，一图流在本机生成后把 `instance/poster/` 传上去。

### 只想看看效果

用大样例初始化（不会去配图，只生成一图流）。下面两份样例照搬了一次真实团建的作品、角色和空缺分布，CN 全是随机生成的假名：

> ⚠️ 这两份样例目前还用着真实的作品名和角色名，公开发布前会换成虚构版本，见 [examples/README.md](../examples/README.md)。

```bash
python3 init.py --example key-demo      # 13 个团、150 个席位（多团）
python3 init.py --example key-single    # 其中一个团、20 个席位（单团）
```

同时开着两个实例对比：`python3 init.py --instance instance-single --example key-single`，再用 `CASTCALL_INSTANCE=instance-single CASTCALL_PORT=5511 python3 server/server.py` 启动第二个。

### 生成的文件

建站生成的东西都在 `instance/` 里：

| 文件 | 是什么 |
|---|---|
| `site.json` | 活动信息和各种开关，手改后刷新页面就生效，不用重启 |
| `roster.json` | 名册，网页保存会改它 |
| `castcall.db` | 报名、留言、名册变更记录（sqlite） |
| `auth.json` | 管理密码的哈希 |
| `uploads/` | 上传的封面、立绘、logo |
| `backups/` | 每次保存前的名册快照（默认留最近 300 份） |

**`instance/` 就是你的全部数据，备份它就够了。** 它已经在 `.gitignore` 里，不会被提交。

忘了密码：`python3 init.py --force` 会重设密码和 `site.json`，名册不动。

## 2. 之后改名册

建站以后名单又变了，用 `tools/import.py` 导入（格式同第 1 步），先加 `--dry` 看会改什么：

```bash
python3 tools/import.py 名单.txt            # 合并：加新团、新角色，空缺补上 CN，已有的 CN 不改
python3 tools/import.py 名单.csv --replace  # 整个换掉（会先备份）
```

其余的在后台改：

登录后台（右下角的锁）：

- **新团 / 加一个团**：团名通常写作品名。可以设主题色、封面、团长、咨询方式和说明，也可以单独暂停这个团的报名。
- **团信息**：每个团展开后的工具条里。
- **添加**：加一个席位。角色名必填，成员留空就是「空缺」，空缺的席位可以报名。
- **立绘**：在席位的编辑框里上传。没有立绘的显示角色名首字。
- **连线视图**：拖动成员到角色，适合大批量换人。
- 席位卡片上的成员名和角色名可以直接点着改。

**工作组**（摄影、后勤、妆娘…）：团的类型选「工作组」，席位写岗位名，不需要立绘。

## 3. 审核报名

有人报名后，后台工具条的「审核」按钮会显示待处理数量。点开以后：

- **通过**：把报名人的 CN 写进那个席位。如果席位已经被别人占了，不会覆盖，会提示你先处理。
- **拒绝**：报名作废，名册不动。
- **撤回**：对已通过的报名使用，席位重新空出来（只有席位上还是这个人时才清）。
- 同一个人对同一个席位 10 分钟内重复提交，只算一次。
